# JNVCKM Alumni Association — website

The website of the **JNVCKM Alumni Association**, the alumni community of
PM SHRI Jawahar Navodaya Vidyalaya, Chikkamagaluru (Seegodu, near Balehonnur,
Karnataka).

The association is the subject here, not the school. The site is a living
record: news and stories, events, the annual meet, IGNITE, the Navodaya Cricket
League, and the projects alumni and batches have funded.

- Canonical: <https://jnvckm.org>
- Secondary: <https://jnvckm.pages.dev>
- Instagram-free, no trackers, no runtime server.

## Stack

| Concern | Choice |
| --- | --- |
| Framework | Astro 7, static output |
| Interactivity | Svelte 5 islands (one island: the contributions filter) |
| Styling | Plain CSS with custom properties; no framework |
| Icons | `lucide-astro` / `lucide-svelte` |
| Fonts | Self-hosted via Fontsource: Arvo, Mukta, Spline Sans Mono, Noto Sans/Serif Kannada |
| Content | JSON in `content/`, edited with Sveltia CMS at `/admin/` |
| Hosting | Cloudflare Pages, project name `jnvckm` |
| Package manager | Bun |

## Commands

```bash
bun install
bun dev                 # http://localhost:4321
bun run check           # TypeScript gate; must be clean
bun run build           # -> dist/
bun run preview         # serve the build
bun run verify          # browser verification against dist/
bun run verify --shots  # ...and write screenshots/
bun run format          # prettier
bun run images          # regenerate WebP derivatives from originals/
bun run logo            # regenerate logo mark, favicons and og-default
```

`bun run verify` builds nothing: run `bun run build` first. It drives a real
Chromium (system `chromium`; override with `CHROME_PATH`) and fails on any
console error, unhydrated island, broken image, horizontal overflow at
320/390/1440, skipped heading level, low-contrast text, over-long measure, a
slop-audit hit, a missing nav link, a 404 internal link, a filter that does not
change the visible count, or a CMS admin that fails to mount.

## Structure

```
content/            JSON content. The CMS edits this; the build consumes it.
  posts/            Stories, news and reports
  events/           Events, workshops, meets, IGNITE editions, NCL seasons
  contributions/    Funded projects and support
  programs/         IGNITE and NCL
  site.json         Association singletons: name, contact, donations
originals/          Untouched source images. Never edit or delete these.
public/
  images/           WebP derivatives generated by `bun run images`
  admin/            Sveltia CMS app + config.yml
  logo-mark.webp favicon.* apple-touch-icon.png og-default.png
src/
  components/       .astro static + one .svelte island
  data/             types.ts, load.ts, one module per collection, activity.ts
  i18n/             ui.ts (en + kn dictionaries), utils.ts (t, lx, isFallback)
  layouts/          BaseLayout.astro (owns <head>)
  lib/              nav.ts (locale-free nav), paths.ts (localePath)
  pages/            Thin routes. Every route exists twice: en and kn/.
  views/            Page implementations
  styles/           tokens.css, global.css
  utils/            format.ts (dates, rupees)
scripts/            verify-site.mjs, optimize-images.mjs, make-logo.mjs
```

## Editing content

Content is JSON, one file per entry, filename = slug. A content edit is a
commit; a build consumes it. There is no sync step and no database.

- **Locally**, no authentication: `bun dev`, open
  <http://localhost:4321/admin/index.html>, choose *Work with Local Repository*
  and pick the repo root. (Chromium only.)
- **In the browser**, via GitHub, once the OAuth worker is deployed and its URL
  is set as `backend.base_url` in `public/admin/config.yml`. See
  `LAUNCH-CHECKLIST.md`.

Bilingual fields store both languages in one file. A record that exists only in
English still renders on Kannada pages: `lx()` falls back to English and the
page tells the reader the archived record is in its original language.

## History

This is a rebuild. The previous site lives on the **`archive`** branch, and the
`originals/` directory holds its images. Six rebuild-only 2024 entries that
could not be corroborated were deliberately **not** migrated; they remain on
`archive`. See `LAUNCH-CHECKLIST.md`.

## Deploy

Cloudflare Pages, Git integration on `main`.

- Build command: `bun run build`
- Output directory: `dist`
- Environment: `BUN_VERSION` pinned
- Project name `jnvckm` (this determines `jnvckm.pages.dev`)

Canonical URLs come from `site` in `astro.config.mjs` (`https://jnvckm.org`).
No `BASE_PATH`: the site is served from a domain root, so no base-prefixing
helper is needed.
